# Scroll-Stopping Hooks

A hook is the first line (and first 1–3 seconds) of a piece of content. Its only job is to make the right viewer stop scrolling and need the next sentence. This skill turns a clear idea into strong hooks by fitting it into proven psychological structures.

Core rule from the source: **Pick a template. Replace the brackets. Keep it specific.**

The full library of 50 templates, grouped by psychological trigger, is in [references/templates.md](references/templates.md). Read it before generating hooks.

## Workflow

1. **Pin down the idea.** You need four things; infer from context, ask only if the idea itself is missing:
   - **Topic / core insight** — the one thing the content teaches or shows.
   - **Audience** — who should stop scrolling (e.g. "beginner photographers", not "everyone").
   - **Payoff** — what the viewer gets by watching to the end.
   - **Proof / asset** — any real numbers, time spent, experiments, before/after, examples the creator actually has. Hooks built on real proof beat invented ones.
2. **Choose triggers, not just templates.** Pick 3–5 psychological triggers from the library that genuinely fit the idea (a myth-busting idea → Contrarian; a real experiment → Test & Experiment; a visual object → Visual Reveal). Do not force a template whose claim the content can't back up.
3. **Fill the brackets with concrete specifics.** Real numbers, named objects, precise audiences, exact timeframes. "7 years", "30-second version", "$4,000", "20 minutes a day" — never "a long time" or "some money".
4. **Write variations.** Default to 5–10 hooks across different triggers so the user can compare angles, unless they ask for a specific count.
5. **Add visual direction** where the format is video and the template benefits from it (see the "Visual" notes in the library). The on-screen image should reinforce the line in the first second.
6. **Self-check** every hook against the checklist below, cut the weak ones, and recommend a top pick with a one-line reason.

## Quality checklist

A hook passes only if:

- **Specific** — contains at least one concrete detail (number, object, audience, timeframe, named method). Swap test: if you could paste it onto a different video unchanged, it's too generic.
- **Short** — speakable in ~3 seconds; aim for under ~20 words, one or two sentences.
- **Audience is obvious** — the right viewer instantly recognises it's for them.
- **Opens a loop** — creates a question, tension, or gap that only the rest of the content closes.
- **Honest** — the content actually delivers what the hook promises. A hook that overpromises kills retention and trust; prefer a slightly smaller true claim.
- **Plain language** — no jargon the target audience wouldn't use; no filler openers ("Hey guys", "So today I want to…").
- **Not a stack** — one clear trigger per hook; don't cram contrarian + list + experiment into one line.

## Output format

Unless the user asks otherwise, respond like this (in the user's language — translate and localise the templates naturally rather than word-for-word; keep numbers and specifics):

```
**Idea:** <one-line restatement> · **Audience:** <who>

1. "<hook line>"
   — Trigger: <trigger name> (template #N)
   — Visual: <what's on screen in the first second>   ← video formats only, when useful

2. ...

**Top pick:** #X — <why it fits this idea and audience best>
```

When the user gives an existing hook to improve: diagnose what's weak (generic? no loop? wrong audience? overpromise?), then give 3–5 rewrites using different triggers.

## Notes

- Templates are skeletons, not scripts: small wording changes are fine as long as the psychological structure stays intact.
- Mix triggers across a batch — five variations of the same template aren't five options.
- For text-first platforms (LinkedIn, X, carousels), drop the visual line and make the first line work standalone before the "see more" cut.
- If the idea is vague ("hooks for my fitness page"), first propose 2–3 concrete content ideas or ask for the specific insight — templates amplify a clear idea; they can't replace one.
